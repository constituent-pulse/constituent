# Constituent

**Your voice. Their vote.**

Mobile-first, nonpartisan civic accountability platform. This repository starts with the approved UI direction and builds screen by screen before backend integration.

## Current scope

- Expo SDK 57 + React Native + TypeScript
- Expo Router
- Locked Constituent design tokens
- UI-001 animated splash screen
- UI-002 placeholder route only

## Run locally

```bash
npm install
npx expo install --fix
npm run start
```

Then open the app in an iOS simulator, Android emulator, development build, or supported Expo Go environment.

## Product rules

1. Preserve the approved dark navy / electric blue visual identity.
2. Build one approved screen at a time.
3. The product is a scoreboard, not a referee.
4. Reward civic participation, never political positions.
5. Keep citizen access free and protect political preference data.
